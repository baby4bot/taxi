## 📖 โปรแกรมนี้คืออะไร

เว็บแอปหน้าเดียว (Single-file Web App) ที่เปลี่ยนมือถือให้เป็น **มิเตอร์แท็กซี่** สำหรับคนขับ
ใช้งานบนหน้ารถจริง — ค้นหาปลายทาง → ประเมินราคาและระยะทาง → นำทาง → จับเวลามิเตอร์
→ ออกใบเสร็จให้ผู้โดยสาร พร้อมระบบสมาชิก/สิทธิ์สำหรับสหกรณ์หรือกลุ่มคนขับ

ออกแบบมาให้ **เปิดค้างไว้ตอนขับได้จริง**: จอเต็ม, ตัวอักษรใหญ่, ปุ่มกดง่าย,
ทำงานต่อได้แม้สลับไปใช้ Google Maps หรือปิดแอปไปแล้ว

## ✨ ฟีเจอร์หลัก

### 🚕 ฝั่งคนขับ (ใช้งานหน้ารถ)

- 🧮 **คำนวณค่าโดยสารอัตราก้าวหน้า** — กรอกระยะทางเอง หรือให้ระบบดึงระยะจากเส้นทางจริง
  เลือกได้ว่าขับ **รถปกติ (35฿)** หรือ **แวน (40฿)**
- 🔍 **ค้นหาปลายทางแล้วประเมินทันที** — ได้ทั้งระยะทาง / เวลา / ราคา / เวลาถึงโดยประมาณ
  (ใช้ **TomTom Search + Routing** ที่คิดเวลารถติดจริง ไม่ใช่แค่ระยะเส้นตรง)
- 📍 **หน้าสรุปเส้นทางก่อนเริ่ม** — ตรวจปลายทางให้ชัดก่อนกดเริ่ม ไม่กดผิดที่
- ▶️ **จับเวลามิเตอร์ (Meter)** — เปิดแล้วนับ **เวลาวิ่ง / เวลารถติด / ระยะทางที่วิ่งจริง** จาก GPS
  มีปุ่ม **หยุดชั่วคราว** และปุ่ม **จบเที่ยว**
- 🧭 **ปุ่มนำทาง Google Maps ในตัว** — ส่งต่อจุดหมายให้ Google Maps นำทางด้วยคำสั่งเดียว
  (คนขับใช้ Google Maps นำทางไปได้เลย แล้วกลับมาเข้าแอป มิเตอร์ยังนับต่อ)
- 🛣️ **ค่าทางด่วน / ค่าบริการเพิ่ม** — เพิ่ม–ลบรายการได้ระหว่างเที่ยว ระบบจำค่าที่ใช้ล่าสุดไว้
  เลือกโหมด **เลี่ยงทางด่วน** หรือ **ขึ้นทางด่วน** ได้
- 💵 **ทอนเงินด่วน (Quick Change)** — กรอกเงินที่รับมา บอกเงินทอนทันที
- 🧾 **ใบเสร็จให้ผู้โดยสาร** — สร้างเป็น **รูปภาพ PNG** ดาวน์โหลด/แชร์ได้ พร้อม QR Code
  ให้ผู้โดยสารสแกนเปิดใบเสร็จของตัวเอง (หัวใบเสร็จใช้ชื่อบริษัท/สหกรณ์ + ทะเบียนรถของคนขับ)
- 📤 **แชร์ค่าโดยสาร** — ปุ่มแชร์บนหัวจอ: **QR Code · Messenger · LINE · TrueMoney · คัดลอกลิงก์**
  (เมนูห้อยลง แตะที่ว่างก็ยุบ และยุบเองใน 2.5 วินาที)
- ⭐ **จุดโปรด + ประวัติการค้นหา** — เก็บไว้ในเครื่อง แตะดาวบนผลค้นหาเพื่อบันทึก
- 🐬 **Service Portal** — รวมเบอร์บริการ / รหัส USSD ที่ใช้บ่อย กดโทรออกได้เลย
- 🎨 **ธีม 3 โหมด** — **มืด** (กรมท่าปกติ) · **ดำ OLED** (ประหยัดแบต/ลดความร้อนจอตอนวางหน้ารถ) ·
  **สว่าง** (มองชัดตอนกลางวัน/แดดจัด) สลับได้จากปุ่มแถวล่างซ้ายของหน้าแรกหรือในหน้าโปรไฟล์
  และซิงก์ข้ามทุกเครื่องของคุณผ่านบัญชีผู้ใช้อัตโนมัติ
- ⚙️ **ตั้งค่าการใช้งาน** — เปิด–ปิดเต็มจอ, สั่น + เสียงติ๊งเมื่อมีแจ้งเตือน,
  **เริ่มต่อเที่ยวค้างอัตโนมัติ**
- 🏷️ **ป้ายเวอร์ชันมุมขวาล่าง** — แตะดูประวัติเวอร์ชันย้อนหลัง แยกเป็นรายวัน

### 👥 ฝั่งผู้ดูแลระบบ

- 🔐 **ระบบสมาชิก** — สมัคร/เข้าสู่ระบบด้วย **Username + รหัสผ่าน ไม่ต้องใช้อีเมล**
  ลืมรหัสผ่านด้วย Username + เบอร์โทรศัพท์
- 🎭 **กำหนดสิทธิ์ (Role & Permission)** — Admin (ได้ทุกสิทธิ์เสมอ) / Manager / User
  สร้างตำแหน่งเองได้ พร้อม **คำขอสิทธิ์เพิ่มรายคน → แอดมินอนุมัติ/ไม่อนุมัติ**
- 🧑‍💼 **จัดการผู้ใช้งาน** — เพิ่ม / แก้ไข / ระงับ / ลบสมาชิก ดูทะเบียนรถ และประวัติการใช้งานรายบุคคล
- 📜 **ประวัติการใช้งานรวมทั้งระบบ (Global Logs)** — พร้อมกล่องเตือน **คำขอสิทธิ์ที่ค้างเกิน 7 วัน**
- 🔔 **จัดการข้อความแจ้งเตือน** — แก้ข้อความ / รูปไอคอน / ระยะเวลาแสดงของ toast ทั้งแอป
- 🧩 **จัดการ Service Portal** — เพิ่ม–ลบ–จัดเรียงหมวดหมู่ ลากสลับลำดับได้
- 📊 **โควตา Firestore** — ดูจำนวนอ่าน/เขียน/ลบที่ใช้ไปวันนี้ แยกตาม ID + เหลือเท่าไหร่
  เทียบโควตาฟรี (อ่าน 50,000 / เขียน 20,000 / ลบ 20,000 ครั้งต่อวัน)
- 🔀 **ลากเรียงลำดับเมนูเองได้** ทั้งเมนูด้านข้าง และเมนูตั้งค่า

## 🛠 เทคโนโลยี

- **Frontend:** HTML + CSS + JavaScript เขียนรวมในไฟล์เดียว (**ไม่มี build step, ไม่มี dependency ในเครื่อง**)
- **Backend / ฐานข้อมูล:** **Firebase Firestore** (สมาชิก, สิทธิ์, ประวัติการใช้งาน, ประวัติเวอร์ชัน)
- **แผนที่ / เส้นทาง:** **TomTom API** (Search + Routing ที่คิดรถติด), **Google Maps Deep Link** (นำทางจริง)
- **PWA:** Service Worker (`sw.js`) + Web App Manifest — ติดตั้งเต็มจอเหมือนแอป
- **UI:** Google Fonts (**Kanit** + Material Symbols), SortableJS (ลากเรียงลำดับ), Canvas (วาดรูปใบเสร็จ)

## 🧬 เบื้องหลังที่คนแก้โค้ดควรรู้

สามเรื่องนี้แก้บ่อยที่สุด และแตะผิดจุดเดียวจะเห็นผลทันทีบนหน้าจอจริง

### 🎨 ระบบธีม (3 โหมด)

- ธีมถูกกำหนดที่แท็ก `<html>` เป็น **คลาสเดียว**: `dark` (ค่าเริ่มต้น) · `oled` (ดำสนิท) · `light` (สว่าง)
- สีทั้งหมดอยู่ใน **CSS Variables** ที่ `:root` และแต่ละธีมมีบล็อกทับสีของตัวเอง (เช่น `html.light { … }`)
  — **ทับเฉพาะชุดสี ไม่แตะเลย์เอาต์/ขนาด** ขนาดปุ่ม ระยะห่าง และตำแหน่งทุกจอจึงเท่ากันทั้ง 3 ธีม
- ตัวคุมอยู่ใน JS: `THEME_ORDER = ['dark','oled','light']` · `applyThemeMode(mode, opts)` ·
  `setThemeMode()` · `cycleThemeMode()` · `syncThemeUi()`
- ปุ่มสลับที่หน้าแรก **วนตามลำดับ** (มืด → ดำ OLED → สว่าง) พร้อมไอคอนบอกโหมด (พระจันทร์ / พระจันทร์มีดาว / ดวงอาทิตย์)
  และในหน้าโปรไฟล์เลือกตรงได้ 3 ปุ่ม
- เก็บค่าที่ **Firestore `users/<uid>.themeMode`** (ซิงก์ข้ามทุกเครื่องของคุณ) + เขียน `oledMode` ควบคู่ไว้ให้บิลด์เก่าอ่าน
  · `localStorage` เป็นสำรองตอนออฟไลน์ · เปลี่ยน `<meta name="theme-color">` ของเบราว์เซอร์ตามธีมด้วย
- **เพิ่มธีมใหม่** = เพิ่มคลาส + บล็อกทับสี แล้วต่อท้าย `THEME_ORDER` — ไม่ต้องแก้โค้ดส่วนอื่น

### 🖼️ รูปโปรไฟล์ และวงแหวนบอกบทบาท

- รูปโปรไฟล์ทุกจุดอยู่ในโครง `<div class="avatar-wrap-ring"><img …></div>`
- **ตัว `<img>` ต้องไม่มีขอบหรือมาร์จินของตัวเอง** — วงแหวนวาดด้วย `.avatar-wrap-ring::before`
  (`conic-gradient` + `mask` เจาะกลาง) เป็น **วงเดียวที่กรอบ** รูปจึงอยู่กลางวงพอดีเสมอ
- สีวงแหวนบอกบทบาท: **Admin = ทอง-ส้ม** · **Manager = ฟ้า** · **User = เงินเทา**
  (ค่าที่ไม่ใช่ 3 นี้ถูกปรับเป็น User อัตโนมัติ)
- ตั้งคลาสด้วย `window.applyAvatarRingRole(role, uid)` **เท่านั้น** — อัปเดตทั้งวงแหวนหัวจอและเมนูข้างพร้อมกัน
  และจำบทบาทไว้ที่ `localStorage['taxi_role_cache_<uid>']` เพื่อให้ได้สีถูกตั้งแต่เฟรมแรกก่อน Firestore ตอบ (ไม่กระพริบเปลี่ยนสี)
- **ป้ายแดงที่มุมรูป** (`.perm-badge`) = มีคำขอสิทธิ์รออนุมัติ — จะโผล่เฉพาะตอนมีเรื่องรอ

### 🎭 บทบาท (Role) และสิทธิ์

| บทบาท | สิทธิ์ย่อ | สีวงแหวนรูปโปรไฟล์ |
|---|---|---|
| **Admin** | ได้ทุกสิทธิ์เสมอ (`godPermsAll()`) — ตั้งค่าได้ทั้งระบบ | ทอง-ส้ม |
| **Manager** | ตามที่กำหนดใน `globalPermissions` ของสหกรณ์ | ฟ้า |
| **User** | ใช้มิเตอร์ + ดู/แก้ข้อมูลของตัวเอง | เงินเทา |
| ตำแหน่งที่สร้างเอง | กำหนดสิทธิ์รายตำแหน่งได้ | เงินเทา |

- สิทธิ์รายคนเพิ่มได้ด้วย `extraPerms` ในเอกสารผู้ใช้ (คนขับยื่น **คำขอสิทธิ์** → แอดมินอนุมัติ/ไม่อนุมัติ)
- **ตรรกะสิทธิ์รวมอยู่ที่ `window.currentUserPerms()`** — เวลาเพิ่มปุ่ม/เมนูใหม่ให้เรียกตัวนี้เสมอ อย่าเช็กชื่อตำแหน่งตรง ๆ
  เพราะตำแหน่งที่สร้างเองกับสิทธิ์พิเศษรายคนจะไม่ถูกนับ
- ระบบ **1 บัญชี = 1 เครื่อง** ใช้ `sessionId` ในเอกสารผู้ใช้ (Admin ยกเว้น ล็อกอินพร้อมกันได้หลายเครื่อง)

### 🗺️ แผนที่โค้ด (หาให้เจอเร็วในไฟล์เดียว)

`index.html` เป็นไฟล์เดียวที่รวมทุกอย่าง — เรียงจากบนลงล่างคือ **CSS → HTML → JS**
ตารางนี้บอกว่าเรื่องไหนอยู่ที่ชื่ออะไร (ค้นหาชื่อนั้นในไฟล์ได้เลย)

| อยากแก้เรื่อง | ไปที่ |
|---|---|
| สี / ระยะห่าง / ขนาดทุกจอ | บล็อก `<style>` ช่วงต้นไฟล์ — ค่าสีรวมอยู่ที่ `:root` แล้วมีบล็อกทับต่อธีม `html.oled` / `html.light` |
| ธีม (สลับ / จำค่า / ไอคอนปุ่ม) | `THEME_ORDER` · `applyThemeMode` · `setThemeMode` · `cycleThemeMode` · `syncThemeUi` |
| วงแหวนรูปโปรไฟล์ | CSS `.avatar-wrap-ring` + `.avatar-wrap-ring.role-*` · JS `applyAvatarRingRole` |
| สูตรค่าโดยสาร | `calcThaiMeterDist` (ช่วงระยะ/อัตราก้าวหน้า) → `currentMeterFare` (ยอดรวม) |
| เริ่ม–จบเที่ยว + หน้าสรุป | `startMeterAndTracking` · `finishTripWithSummary` · `renderTripSummary` |
| บันทึกเที่ยว + คิวออฟไลน์ | `saveTripToFirestore` · `drainTripSyncQueue` · `tripQueueCount` |
| สิทธิ์ผู้ใช้ | `currentUserPerms` · `effectiveRolePerms` · `godPermsAll` |
| โหลดข้อมูลสมาชิกขึ้นหน้าจอ | `__applyUserDocUI` |
| ประวัติเวอร์ชันรายวัน | `APP_RELEASE_NOTES` · `CHANGELOG_SEED` · `chgMerge` · `addChangelogEntry` |
| เปิด Google Maps นำทาง | `__openMapsToDest` |
| ทางสำรองเมื่อ SDK ค้าง (ยิง REST ตรง) | `__fsTimeout` · `__fsRestGet` · `__fsRestPatch` · `__fsRestQuery` · `__fsRestAdd` |
| เที่ยวค้าง/เบิกคืนเวลาหลังปิดแอป | `autoCatchUpSavedTrip` · `catchUpDrivenKmAfterHidden` · `catchUpKmViaRoutePolyline` |

> 💡 ไฟล์ยาว ~10,000 บรรทัด — ใช้การค้นหาชื่อฟังก์ชันจากตารางนี้แทนการเลื่อนหาจะเร็วกว่ามาก
> และไฟล์สำรองรายรอบอยู่ในชื่อ `index - N <สิ่งที่แก้>.html` (เก็บไว้เทียบย้อนหลัง)

## 🚀 วิธีใช้งาน

### สำหรับคนขับ
1. เปิด **https://baby4bot.github.io/taxi/** ในมือถือ
2. สมัคร/เข้าสู่ระบบ แล้วกรอกโปรไฟล์: ชื่อ, **ชื่อบริษัท/สหกรณ์**, **ทะเบียนรถ**, QR Code รับเงิน
3. แนะนำให้กดติดตั้งแอป (แบนเนอร์ "ติดตั้งแอปเต็มจอไว้ใช้ประจำไหม?") → ได้จอเต็มถาวร เหมาะกับวางบนแท่นรถ
4. กรอกระยะทางเอง หรือค้นหาปลายทาง → ตรวจหน้าสรุปเส้นทาง → กด **เริ่มจับเวลามิเตอร์**
5. กดปุ่มนำทางเพื่อใช้ Google Maps นำทางได้เลย — กลับเข้าแอป มิเตอร์ยังนับต่อ
6. จบเที่ยว → ดูสรุปค่าโดยสาร → แชร์/ออกใบเสร็จให้ผู้โดยสาร

### สำหรับผู้ดูแลระบบ
1. ล็อกอินด้วยบัญชี **Admin**
2. เมนูด้านข้าง → **ตั้งค่าการใช้งาน** → จัดการผู้ใช้ / สิทธิ์ / ข้อความแจ้งเตือน / Service Portal
3. ระบบจะขึ้น **ป้ายแดง** ที่ไอคอนโปรไฟล์–เมนู เมื่อมีคำขอสิทธิ์รออนุมัติ

## ⏱️ ความน่าเชื่อถือตอนขับจริง (จุดที่ออกแบบมาพิเศษ)

แอปนี้ต้องทนกับสถานการณ์จริงหน้ารถ จึงมีกลไกเฉพาะเหล่านี้:

- 🔁 **เริ่มต่อเที่ยวค้างอัตโนมัติ** — เผลอปิดแอป/รีเฟรช/ย่อหน้าต่างไว้ เปิดใหม่แล้วมิเตอร์เดินต่อให้
  พร้อมเปิดจอมิเตอร์ใหญ่และ **เสียง + สั่นเตือน** ว่ามิเตอร์เริ่มต่อแล้ว (ตั้งค่าเปิด/ปิดได้)
- 🧷 **กันระยะทาง–เวลารถติดเพี้ยนหลังปิด/ย่อแอป** — ระบบจำ "ฐานหลักฐาน" ณ วินาทีที่แอปถูกซ่อน/ปิด
  (ระยะทาง + เวลารถติด + ตำแหน่ง) แล้วเบิกคืนจากฐานนั้นครั้งเดียว → ตัวเลขไม่บวมและไม่หายข้ามรีเฟรช
- 🧾 **การ์ดหลักฐานการเบิกคืน** — ในหน้าสรุปค่าโดยสารมีหัวข้อบอกช่วงที่แอปถูกปิดและยอดที่เบิกไป เพื่อตรวจย้อนหลังได้
- ⏳ **จำกัดเวลาจอดที่เบิกหลังปิดแอปได้** — กันค่าโดยสารบวมถ้าลืมจบเที่ยวข้ามคืน

## 💾 ข้อมูลถูกเก็บไว้ที่ไหน

| ข้อมูล | เก็บที่ | หมายเหตุ |
|---|---|---|
| บัญชีสมาชิก / สิทธิ์ / ประวัติการใช้งาน | **Firestore** (`users`, `global_logs`) | ซิงก์ข้ามเครื่อง |
| ประวัติเวอร์ชัน (changelog รายวัน) | **Firestore** (`system/changelog`) | อัปเดตขึ้นเว็บแล้วเห็นทันที |
| Service Portal / ข้อความแจ้งเตือน | **Firestore** (`system/...`) | แก้ผ่านหน้าแอดมิน |
| เที่ยวที่กำลังจับเวลาอยู่ | **ในเครื่อง** (`localStorage`) | เพื่อกู้เที่ยวค้างหลังปิดแอป |
| จุดโปรด / ประวัติการค้นหา / โหมดทางด่วน | **ในเครื่อง** | ล้างได้จาก "รีเซ็ตการตั้งค่า" |
| ธีมที่เลือก | **Firestore `users/<uid>.themeMode`** + `localStorage` | ซิงก์ข้ามเครื่อง · ค่าในเครื่องเป็นสำรองตอนออฟไลน์ |
| บทบาทล่าสุดที่จำไว้ (`taxi_role_cache_<uid>`) | **ในเครื่อง** | ใช้ตั้งสีวงแหวนตั้งแต่เฟรมแรก แล้วเขียนทับด้วยค่าจริงจาก Firestore ทุกครั้งที่โหลดโปรไฟล์ |
| เที่ยวที่จบแต่ยังส่งไม่สำเร็จ (คิวรอซิงก์) | **ในเครื่อง** (`taxi_pending_trips_v1`) | ส่งขึ้น Firestore ให้เองเมื่อเน็ตกลับมา/กลับเข้าแอป |

## ⚠️ ความปลอดภัย

- การเข้าถึงข้อมูลทั้งหมดถูกควบคุมด้วย **สิทธิ์ตาม Role** (Admin / Manager / User) ที่ตั้งใน Firestore
- คีย์ Firebase ที่อยู่ในไฟล์เป็น **คีย์ฝั่งเว็บของ Firebase** (ใช้ระบุโปรเจกต์) —
  ความปลอดภัยจริงอยู่ที่ **Firestore Security Rules** ต้องตั้งให้รัดกุมก่อนใช้งานจริง
- ห้าม commit รหัสผ่านจริง ข้อมูลผู้โดยสาร หรือข้อมูลส่วนตัวลง repository
- คีย์ API ของ TomTom มีโควตาฟรีต่อวัน แอปมีการนับและเตือนในเครื่องเมื่อใกล้เต็ม
