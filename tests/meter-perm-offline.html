🧪 ชุดทดสอบออฟไลน์: สิทธิ์ “เริ่มมิเตอร์จากหน้าสรุปเส้นทาง”

โหลดแอปจริง (../index.html?fsNowrite=1) ใน iframe · ตัดเน็ตทั้งหมด · กดปุ่มจริง startTripFromPreview() (ปุ่ม “เริ่มมิเตอร์” ในหน้าสรุปเส้นทาง) และ toggleManualTimer() (ปุ่มจับเวลามิเตอร์ปกติ) แล้วอ่านสถานะจริงจากแอป
ผู้ใช้สั่ง (19 ก.ย. 69): “เพิ่มสิทธิ์เรื่องเริ่มจับเวลามิเตอร์ — ค่าเริ่มต้นให้ทุกยศยกเว้น user · user กดแล้วขึ้นข้อความว่าสิทธิ์มิเตอร์ใช้ได้ตั้งแต่ VIP ขึ้นไป · แต่ปุ่มจับเวลามิเตอร์ปกติให้เขาใช้ได้เพราะไม่มีอะไร”
ตรวจ 8 ชั้น: ① ค่าเริ่มต้น User=ปิด · VIP/ผู้จัดการ/แอดมิน=เปิด ② User กดปุ่ม → มิเตอร์ไม่เริ่ม · หน้าสรุปไม่ปิด · มีข้อความแจ้ง ③ VIP/VIP ทดสอบกดจริง → มิเตอร์เริ่ม ④ ปุ่มจับเวลามิเตอร์ปกติยังใช้ได้กับ User ที่ไม่มีสิทธิ์ (ของเดิมไม่พัง) ⑤ แอดมินติ๊กเปิดให้ User → กดได้จริง ⑥ มอบรายคน (extraPerms) ทับสิทธิ์ยศได้ ⑦ หน้าตั้งค่าสิทธิ์มีแถวใหม่ + บันทึกส่งคีย์ไปจริง ⑧ สิทธิ์เดิม (มินิมัล/ความเร็ว) ไม่ถูกกระทบ
